# innovation-lab-early-case-management-tool

To run this repository, install requirements from `requirements.txt` by running this command:
`pip install -r requirements.txt`

If using Codespaces, run this command instead: `python -m streamlit run app.py`

Add the gemini api key: `export GEMINI_API_KEY=xxx`

Then run the app:
`streamlit run app.py`
